# GregTech: Tier Zero
GregTech: Tier Zero is a modern GregTech modpack where you serve as a prisoner for your crimes. Your goal is to finish all of the tasks of your sentence, and maybe, just maybe you'll be able to leave tier zero.

# Playing
Modpack is not public yet. You will need to build from source

# Building
[Packwiz](https://packwiz.infra.link/) will allow you to build the pack.
Please refer to their tutorials page for more info.

# AI Policy
This project will never use any AI for creative based content such as assets, art, textures, or quests. For the full policy read AI_POLICY.md
